# Colette / Collegiate Tetris League Discord Bot

This bot is a project for the Collegiate Tetris League. It currently supports the blindpick / ban system for the 2026 CTL season, amongst other features such as showing standings, matchups, and submitting pick'ems.

## How to Maintain

More information on how to maintain the bot will be added here soon.

## How to Use

This bot is in the CTL Discord Server as colette#5480. I probably should add a /help command eventually, but below are some of the commands.

### Bans and Blindpicks

- Initiate a match with opponent using `/match start [captain 1] [captain 2]`
- Each captain sets their team roster with `/match roster [team name] [player 1] ... [player 5]` (use tetrio usernames)
- Each captain bans a player from the opponent's team with `/match ban [player]` (leave blank to pass the ban, in the case that you are banning the opposing team below 3 players, which isn't allowed)
- Second ban stage, same as above
- Each captain blindpicks a player from their team with `/match blindpick [player]`

### Standings

- Check standings with `/standings [bracket] [entries]`

### Matchups

- Check matchups (and scores) with `/matchups [bracket] [week] [entries]`

### Pick'ems

- Make a copy of the [pick'ems template](https://docs.google.com/spreadsheets/d/1Zi2H-2dtaIpBpSnZMTtUC_cbBxuNPv2zvLsy8jBDqJE/edit?usp=sharing) and follow the instructions
